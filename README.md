# Telegram Join Approver Bot

بوت بسيط بلغة PHP للموافقة اليدوية على طلبات الانضمام في قنوات تيليجرام.

## التشغيل
1. ضع ملفات البوت على استضافة تدعم PHP.
2. عيّن عنوان السكربت كويب هوك:

```
https://api.telegram.org/bot<token>/setWebhook?url=<YOUR_URL>/index.php
```

3. تأكد من منح البوت صلاحية "إدارة طلبات الانضمام" في القنوات المطلوبة.
4. اترك الويب هوك يعمل باستمرار ليتمكن البوت من تسجيل طلبات الانضمام الجديدة.

يتم حفظ القنوات التي يضاف إليها البوت تلقائيًا في `data/channels.json` عند رفعه كمشرف.
كما يتم تخزين طلبات الانضمام الواردة مؤقتًا في ملفات باسم `pending_<id>.json` داخل المجلد `data/` ليتمكن البوت من قبولها لاحقًا.

## المجلدات
- `index.php` : نقطة الدخول للويب هوك.
- `functions.php` : دوال المساعدة والتخزين.
- `data/` : تخزين الجلسات والقنوات والطلبات مؤقتًا.
